# 📄 Nota Kilat

Aplikasi web untuk membuat **Faktur**, **Kuitansi**, dan **Nota** secara instan langsung di browser — tanpa perlu login, tanpa server, dan tanpa instalasi.

🔗 **Demo:** [nota-kilat-8lg2.vercel.app](https://nota-kilat-8lg2.vercel.app)
📦 **Repository:** [github.com/ruwahna/nota-kilat](https://github.com/ruwahna/nota-kilat)

## ✨ Fitur

- **3 Jenis Dokumen** — Faktur, Kuitansi, dan Nota dalam satu aplikasi
- **Live Preview** — Isi formulir di kiri, dokumen langsung tampil di kanan secara real-time
- **7 Tema Warna** — Zamrud, Nila, Bata, Kunyit, Plum, Laut, dan Arang
- **3 Gaya Desain** — Klasik, Tegas, dan Minimalis
- **Terbilang Otomatis** — Konversi angka ke teks Rupiah secara otomatis
- **Cetak / Simpan PDF** — Langsung cetak atau simpan sebagai PDF dari browser
- **Salin Ringkasan** — Salin ringkasan dokumen untuk dikirim via WhatsApp atau email
- **Auto-Save** — Data tersimpan otomatis di browser (localStorage)
- **Upload Logo** — Tambahkan logo usaha pada dokumen
- **Responsive** — Tampilan menyesuaikan di desktop maupun mobile
- **Dark Mode** — Otomatis mengikuti preferensi sistem

## 🚀 Cara Pakai

1. Buka file `index.html` di browser
2. Pilih jenis dokumen: **Faktur**, **Kuitansi**, atau **Nota**
3. Isi data usaha, pelanggan, dan rincian barang/jasa
4. Dokumen langsung tampil di panel pratinjau
5. Klik **Cetak / Simpan PDF** untuk mencetak atau menyimpan

## 📁 Struktur File

```
web nota,kwitansi/
├── index.html   # Halaman utama (HTML)
├── style.css    # Stylesheet (CSS)
├── script.js    # Logika aplikasi (JavaScript)
└── README.md    # Dokumentasi
```

## 🛠️ Teknologi

- **HTML5** — Struktur halaman
- **CSS3** — Styling dengan CSS custom properties & dark mode
- **JavaScript (Vanilla)** — Logika tanpa framework/library tambahan
- **Google Fonts** — Bricolage Grotesque, Instrument Sans, JetBrains Mono

## 📸 Jenis Dokumen

| Jenis | Ukuran | Keterangan |
|-------|--------|------------|
| Faktur | A4 | Lengkap dengan PPN, diskon, jatuh tempo, dan info rekening |
| Kuitansi | A4 | Bukti penerimaan uang dengan terbilang dan materai |
| Nota | 80 mm | Format struk ringkas untuk transaksi sederhana |
