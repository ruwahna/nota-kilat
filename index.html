Koneksi Google Spreadsheet (Online) Belum Terhubung

Cara menyambungkan ke Google Spreadsheet Anda:

  1. Buka sheets.new untuk membuat Google Spreadsheet baru.
  2. Di menu atas Google Sheets, klik Ekstensi (Extensions) > Apps Script.
  3. Hapus kode yang ada, lalu tempel kode berikut: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tanggal", "No Dokumen", "Jenis", "Nama Pelanggan/Pembayar", "Keterangan", "Total (Rp)"]);
    sheet.getRange(1, 1, 1, 6).setFontWeight("bold").setBackground("#D1E7DD");
  }
  var data = JSON.parse(e.postData.contents);
  if (Array.isArray(data)) {
    data.forEach(function(r) { sheet.appendRow([r.date, r.no, r.type.toUpperCase(), r.buyer, r.desc, r.total]); });
  } else {
    sheet.appendRow([data.date, data.no, data.type.toUpperCase(), data.buyer, data.desc, data.total]);
  }
  return ContentService.createTextOutput("OK").setMimeType(ContentService.MimeType.TEXT);
}
  4. Klik tombol biru Deploy (Terapkan) > New deployment (Penerapan baru). Pilih jenis roda gigi ⚙️ Web app.
  5. Pada "Who has access" (Siapa yang memiliki akses), pilih Anyone (Siapa saja). Lalu klik Deploy.
  6. Salin Web app URL yang muncul, tempel pada kolom di atas, lalu klik Simpan URL. Selesai! Dokumen akan otomatis masuk ke Google Spreadsheet setiap kali dibuat. 🎉
